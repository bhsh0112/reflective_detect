## 1、现有效果简单介绍

### （1）衣物种类检测

​	现有模型会检测图片或视频中三类物体：reflective_clothes（即穿戴反光衣）,hat（即安全帽）,person(即人)。并将检测结果用不同颜色的长方形框框出。

### （2）依据逻辑输出判定结果

本项目有两个输出：

#### ①图像输出

在图片或视频左上角根据检测到的衣服种类输出特定文本：

​		若有人未穿反光衣或佩戴安全帽，图像左上角输出"error"

​		若全员穿戴反光衣并佩戴安全帽，图像左上角输出"ok"

#### ②UDP输出

​		若有人未穿反光衣或佩戴安全帽，图像左上角输出"有人未穿反光衣或佩戴安全帽"

​		若全员穿戴反光衣并佩戴安全帽，图像左上角输出"全员佩戴反光衣和安全帽"

## 2、环境配置

### （1）填写上位机ip及端口

将reflect_detect目录下的“detect.py”的280、281行的`UDP_IP`和`UDP_PORT`分别修改为自己上位机的ip和端口
